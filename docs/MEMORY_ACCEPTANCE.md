## 已覆盖链路

- 查证：初始记忆、主动查询和保存、精确查重、结果回传、复审候选保存与自动经验提取，沿用现有记忆测试。
- 规划：读取当前范围约束与经验；本次设备条件仍保存在方案中；其他用户和任务的记忆不进入提示词。
- 实验分析：相关经验单独进入上下文，统计数据和导入快照保持不变。
- 初稿：偏好与相关经验进入写作上下文；论文证据编号与引用校验保持独立。
- 普通扩写：对已有初稿重新读取最新记忆，生成建议后不直接保存。
- Skill扩写：意图路由不加载研究记忆，真正扩写时加载；接口参数传递完整。
- 无记忆时生成、读取与下载；直接生成导出和研究报告ZIP结构有效。
- 超出必要记忆预算时停止生成并返回错误；记忆编号不能替代论文资料编号。

## 验收边界

使用独立SQLite数据库、模拟DeepSeek文本响应及模拟embedding，HTTP接口、数据库存储、统计与导出逻辑实际执行。未调用真实大模型，未向外部服务发送论文内容，未迁移正式MySQL、重启服务或提交GitHub。

这些结果证明调用链、范围、格式、统计与保存行为符合测试断言，不证明真实模型一定遵守全部提示词，也不评估真实检索阈值、写作质量、Token成本或响应时延。真实模型效果验收另行进行。
