# 科研工作台前端

Vue 3 + Vite，使用JavaScript。七个页面：论文资料库、研究任务、作业与报告、研究方案、实验结果、论文写作、服务状态。完整操作见[七阶段使用指南](../USER_GUIDE.md)。

Windows用户请先阅读[WSL2安装指南](../WINDOWS.md)，以下npm命令在Ubuntu环境执行；不要将Windows的node_modules复制到WSL。

## 开发与构建

从项目根目录执行：

```bash
cd frontend
npm ci
npm run dev
```

测试与构建也在frontend目录执行：

```bash
npm test
npm run build
```

开发地址为http://127.0.0.1:5173/app/，请求`/api/...`经Vite代理到FastAPI。构建页面使用同源后端路径；`npm run preview`使用4173端口及配置的后端代理。

后端从frontend/dist提供`/app/`。前端修改后重新构建并刷新；后端修改后重启API。未构建时503会提示构建命令。

## 页面功能

| 页面 | 主要能力 |
| --- | --- |
| 论文资料库 | 论文信息、PDF上传和删除、后台准备、原文查看 |
| 研究任务 | 关联论文、检索与问答、分析审校、修订建议、条件采纳及版本恢复 |
| 作业与报告 | 跟踪作业、按归属查询服务端历史并翻页、查看及下载对比报告 |
| 研究方案 | 选择已通过审校的报告、生成候选问题、保存选择、生成方案 |
| 实验结果 | 按方案上传CSV、按编号恢复、选择多指标统计、绘图、生成分析与研究报告ZIP |
| 论文写作 | 按实验或初稿编号恢复、生成并保存初稿、章节扩写建议、人工修改及确认保存、下载 |
| 服务状态 | 依赖正常、异常或未确认状态；不据此自动停止作业 |

作业完成不等于报告审校通过，passed=false显示“待核验”。模型文字使用普通文本渲染，不使用v-html。

## 初稿扩写和保存

生成建议调用POST `/paper-drafts/{id}/expand`，不保存正文。确认时复制当前完整content并替换选定章节，通过PATCH `/paper-drafts/{id}`保存；下载GET `/paper-drafts/{id}/export`使用已保存正文，不再次生成。

建议段落支持编辑文字和放弃。切换初稿、章节、扩写要求或写作范围会清除建议；保存失败保留建议供重试。用户确认后原地更新，没有初稿修订历史。

“一句话扩写（Skill）”调用POST `/paper-drafts/{id}/skill`，把用户要求交给模型识别，再调用既有扩写能力；含糊请求显示补充问题。Skill结果与手动扩写共用建议预览、编辑、放弃和PATCH确认保存。成功通常有两次模型调用，页面等待不代表后台任务队列。

## 浏览器记忆与服务器数据

作业跟踪只在浏览器保存类型、编号和归属编号，正文从服务器读取；服务端历史可在作业页按论文或任务查询。

研究方案记住最近问题集编号；实验页记住最近导入编号；写作按实验导入记住最近初稿编号。正文和材料快照保存在MySQL，未确认的扩写建议只在内存中。换浏览器可手动输入编号恢复。

修改写作范围或实际研究说明会清除当前初稿预览，不删除数据库记录；可按初稿编号重新打开。

## 目录

- src/views：七个页面。
- src/components：表单、统计图表、方案、初稿、来源和报告展示。
- src/services/api.js：请求、超时、模型调用和文件下载封装。
- src/composables/useJobs.js、useJobHistory.js：后台跟踪和服务端历史。
- src/composables/useResearchPlanning.js：候选问题、选择及方案。
- src/composables/useExperimentWorkspace.js：实验和写作共享状态，扩写与确认保存。
- tests：API、状态逻辑及组件服务端渲染测试；模拟外部请求，不产生模型用量。

参考.env.example设置公开代理目标VITE_API_TARGET。数据库密码和模型密钥只在后端配置，不放进前端。
