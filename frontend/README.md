# 科研工作台前端

Vue 3 + Vite，使用JavaScript。已有四个页面：论文资料库、研究任务、作业与报告、服务状态。

## 开发与构建

```bash
cd /Users/wenxulong/research_library/frontend
npm ci
npm run dev
npm test
npm run build
```

开发地址 http://127.0.0.1:5173/app/ 。开发请求 `/api/...` 经Vite转发到FastAPI；构建后的页面使用同源后端路径。`npm run preview`可在4173端口检查构建结果，已配置后端路径代理。

后端从frontend/dist提供 `/app`、`/app/` 和 `/app/assets`。后端运行旧代码时需重启API才能加载挂载变更；未构建时503会提示构建命令。FastAPI端口8000，默认保持本机访问。

## 页面功能

- 论文：搜索、添加、编辑、删除；上传/删除PDF；后台准备；查看正文。删除有确认窗口。旧PDF的准备结果不会冒充新PDF的结果。
- 任务：创建/删除，关联/移除论文；本地语义检索、RAG问答、结构化分析、审校、修订复审；显示版本前后变化、恢复历史。
- 采纳：当前后端只允许符合条件的陈述移动到证据备注。前端只为合格移动建议提供采纳按钮，没有通用“采纳全部修订”接口。
- 作业：跟踪准备/报告进度、错误和结果；查询已有编号；显示并下载报告。作业完成不等于审校通过，passed=false明确显示“待核验”。
- 引用：保留资料编号，点击后展示准确文本块及所在页；找不到旧块会提示资料变化。模型文本按普通文字渲染，不使用v-html。
- 服务：显示正常、异常或未确认；solo Worker忙时可能不回复，不因此自动停止作业。

本浏览器只存作业类型、编号和归属编号，不存报告正文。刷新后继续查询。历史作业可在“作业与报告”输入编号恢复显示；这里不是完整数据库作业列表。

生成回答、分析、审校、修订、采纳核验和生成报告会调用DeepSeek，按钮附近标明用途。前端验证使用本地检索和已有报告，没有发送新内容至DeepSeek。

## 目录

src/views是四个页面；src/components是弹窗、引用、分析和报告组件；src/services集中封装API与轮询规则；src/composables/useJobs.js管理跨页面作业跟踪。

参考.env.example设置公开代理目标VITE_API_TARGET，不把数据库密码或模型密钥放入前端。
